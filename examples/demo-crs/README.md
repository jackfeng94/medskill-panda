# DEMO-CRS example (ENT) · Ví dụ DEMO-CRS (Tai Mũi Họng)

**English.** A complete ENT example built with this plugin's own tools from **simulated data**
(seed 7): a randomised trial of structured postoperative care (steroid irrigation and scheduled
endoscopic visits) versus usual care after endoscopic sinus surgery for chronic rhinosinusitis with
nasal polyps; primary outcome, endoscopic polyp recurrence within 24 months. It is not a real study; every number in it is computed by `make_data.py` and
stored in `out/results.json`.

| Output | File |
|--------|------|
| HTML deck (English, Vietnamese), one offline file each | `deck_en/out/demo-crs.html`, `deck_vi/out/demo-crs.html` |
| PowerPoint journal club, 12 slides (English, Vietnamese: title, agenda, PICO, schema, figures with takeaways, chart, effect sizes, appraisal, bottom line, references, closing) built inside a branded template, and its PDF | `pptx_en/out/demo-crs.pptx`, `pptx_vi/out/demo-crs.pptx`; template from `make_template.py` in `theme/` |
| Manuscript, full IMRaD (Word: English text with a Vietnamese abstract, cited introduction, methods, results with table and figure, discussion, references) and its PDF | `manuscript/demo-crs.docx`, `manuscript/demo-crs.pdf` |
| Figures and every computed number | `out/` |
| Chart gallery: eight chart types, SVG, English and Vietnamese | `out/charts/en/`, `out/charts/vi/`, values in `out/charts/values.json` |
| Screenshots used in the main README (regenerated by `build.sh`, not committed) | `screens/` |

The HTML decks pass `lint_slop.py` with 0 findings; the PowerPoint decks pass `check_pptx.py`
and `lint_slop.py` with 0 findings. `lint_prose.py` reports one error on the
manuscript, on purpose: `[MISSING: authors to confirm]`, a gap only the authors can fill.

Rebuild everything (needs numpy, matplotlib, python-docx, pymupdf, LibreOffice and Node
Playwright):

```bash
sh examples/demo-crs/build.sh
```

**Tiếng Việt.** Ví dụ Tai Mũi Họng trọn vẹn dựng bằng chính công cụ của plugin từ **dữ liệu mô phỏng**
(seed 7): thử nghiệm ngẫu nhiên chăm sóc có cấu trúc sau mổ (rửa mũi corticoid, tái khám nội soi theo
lịch) so với chăm sóc thường quy sau phẫu thuật nội soi xoang ở bệnh nhân viêm mũi xoang mạn có polyp;
tiêu chí chính là tái phát polyp trên nội soi trong 24 tháng. Đây không phải nghiên cứu thật; mọi con số do `make_data.py` tính và lưu trong
`out/results.json`. Mở `deck_vi/out/demo-crs.html` để xem bộ slide tiếng Việt, và
`manuscript/demo-crs.docx` để xem bản thảo (nội dung tiếng Anh, tóm tắt tiếng Việt). Dựng lại
toàn bộ bằng lệnh `build.sh` ở trên.
