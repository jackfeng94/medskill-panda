# Question tree for medical presentations

Each node is a decision. Children open only when the parent is settled. Recommend an answer
for every question, and give the reason in one clause.

## Root (round 1)

| Decision | Typical options | Why it matters |
|---|---|---|
| Deck type and purpose | journal club (report / critique / change practice) · conference talk · teaching lecture · guideline update · clinical case · M&M · grand rounds · thesis defence · patient education | Sets the storyline recipe in deck-planning |
| Audience | students · residents · specialists · mixed MDT · nurses/pharmacists · patients | Sets depth, jargon, how much to explain |
| Duration | talk minutes + Q&A minutes | Slide budget ≈ 1 content slide per minute |
| Language | Vietnamese · English · bilingual; keep English drug/trial terms? | Terminology and number format (0,58 vs 0.58) |
| Output format | HTML · PPTX · both | Build skill, animation, editability |
| Template | institutional .pptx/.potx · congress template · reference deck · none | Theme, logo, header/footer, closing slide |
| Sources | PDFs supplied · guideline document · case notes · research needed | Whether evidence-research searches |
| Presenter and event | exact printed name, title, affiliation; event name, date | Title slide; avoids misspelt names |

## Branches

### Journal club
- Report only, or critique? If critique: which checklist (CASP, RoB 2, CONSORT, STROBE, PRISMA)?
- Single paper, or paper plus context (prior trials, guidelines)?
- Discussion questions at the end? How many?
- Show the original figures (education reuse), or rebuild them?

### Conference / research talk
- Strict time limit with a chair? Rehearsal timing needed in notes?
- Is the presenter an author? If yes, unpublished data rules and conflicts slide.
- Required disclosure / COI slide format?

### Teaching lecture
- Learning objectives (2–4), assessed afterwards?
- Learners' prior knowledge; which misconceptions to target?
- Interactive elements: questions to the audience, quiz slides, cases?
- Handout needed (PDF export)?

### Guideline update
- Which guideline, which version, versus which previous version?
- Focus: what changed, or the whole guideline?
- Show recommendation class and level of evidence? Local adaptation for the hospital?

### Clinical case / M&M
- Consent obtained? De-identified by whom? Images owned by the hospital?
- Timeline granularity (days, hours); which investigations matter?
- Teaching points (2–3) and the literature to support them?
- M&M: systems focus, no blame; which classification of error?

### Figures and motion
- Reuse original figures (Kaplan–Meier, forest plots) or rebuild? Recommend **reusing the
  original vector figure** whenever the source PDF is supplied: it is exact and can be
  recoloured and animated (medical-figures). Rebuild from numbers only when there is no PDF
  or the figure is raster and unreadable. Flag reuse rights if the talk will be recorded.
- Motion graphics: none · subtle reveals · explanatory mechanism animation (HTML only)
- Medical illustrations: libraries first (Servier Medical Art, Bioicons, NIH BioArt), AI-generated only when no library has the picture, or the user's own images?
- If AI may be needed: which account does the user have, ChatGPT, Gemini, both or neither? Record it in the brief (Figures line); it decides which service is used, and "neither" means no AI images.

### Template branch (when a template is supplied)
- Use its title and closing layouts as-is? Keep its logo (check the event allows it)?
- Template is 4:3 but projector is 16:9 (or the reverse): adapt or keep?

### Delivery
- Venue projector aspect ratio and whether the room has internet
- Presenter laptop: Windows/macOS, PowerPoint version, browser
- Need a PDF backup?
